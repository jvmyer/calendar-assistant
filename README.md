# calendar-assistant

Persönlicher Planungsassistent (Arbeitstitel): wertet Mails, ILIAS und Telegram-Nachrichten aus, leitet daraus Aufgaben ab und plant sie automatisch als Blocker in Google Kalender ein. Läuft self-hosted, KI-Verarbeitung lokal.

Status: Konzeptphase – siehe [docs/KONZEPT.md](docs/KONZEPT.md).
